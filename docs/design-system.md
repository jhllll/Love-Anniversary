## 1. 设计理念

### 1.1 核心关键词

> **温柔、浪漫、轻盈、甜美、不打扰**

- **温柔**：粉色系渐变，避免高饱和度刺眼色彩
- **浪漫**：爱心粒子、情话卡片、圆角曲线
- **轻盈**：毛玻璃半透明、柔和阴影、大留白
- **甜美**：emoji 图标、心形交互、轻快动效
- **不打扰**：无广告、无推送、无负载，打开即用

### 1.2 情绪板

```
主色调印象：日出时的粉色云层
质感印象：  磨砂玻璃上凝结的水珠
动效印象：  微风拂过花瓣轻轻飘落
排版印象：  手写情书的温柔与郑重
```

## 2. 色彩系统

### 2.1 主色板

| Token | 色值 | 预览 | 用途 |
|-------|------|------|------|
| `--pink-light` | `#fbc2eb` | 浅粉 | 背景渐变终点 |
| `--pink` | `#ff9a9e` | 主粉 | 背景渐变起点、按钮、强调 |
| `--pink-deep` | `#e8728a` | 深粉 | 按钮渐变、数字颜色、激活态 |
| `--peach` | `#fad0c4` | 蜜桃色 | 背景渐变中点 |

### 2.2 中性色

| Token | 色值 | 用途 |
|-------|------|------|
| `--white` | `#ffffff` | 纯白底 |
| `--white-80` | `rgba(255,255,255,0.8)` | 毛玻璃卡片、导航栏背景 |
| `--white-60` | `rgba(255,255,255,0.6)` | 次要按钮背景 |
| `--white-30` | `rgba(255,255,255,0.3)` | 毛玻璃边框、分割线 |
| `--white-15` | `rgba(255,255,255,0.15)` | 预留 |

### 2.3 文字色

| Token | 色值 | 用途 |
|-------|------|------|
| `--text` | `#4a3040` | 主文字（卡片内深色文字） |
| `--text-light` | `#7a6070` | 辅助文字（标签、说明） |

### 2.4 背景渐变

```css
/* 全局背景 */
background: linear-gradient(
  135deg,
  var(--pink) 0%,
  var(--peach) 50%,
  var(--pink-light) 100%
);
background-attachment: fixed;
```

```
渐变方向：左上 → 右下（135deg）
起点：#ff9a9e（粉色）
中点：#fad0c4（蜜桃色）
终点：#fbc2eb（浅粉色）
```

### 2.5 使用规则

| 规则 | 说明 |
|------|------|
| 不可自定义色值 | 所有颜色必须通过 CSS 变量引用 |
| 对比度 | 白色文字在粉色背景上确保可读（文字阴影辅助） |
| 暗色模式 | v1.0 暂不支持，默认仅浅色主题 |
| 渐变色禁用于文字 | 仅用于背景、按钮、进度环 SVG |

## 3. 字体系统

### 3.1 字体族

```css
/* 正文字体栈 */
font-family:
  -apple-system,          /* iOS Safari */
  BlinkMacSystemFont,     /* macOS Chrome */
  "Segoe UI",             /* Windows */
  "PingFang SC",          /* 中文 - macOS/iOS */
  "Hiragino Sans GB",     /* 中文 - macOS 旧版 */
  "Microsoft YaHei",      /* 中文 - Windows */
  "Helvetica Neue",
  Helvetica, Arial,
  sans-serif;

/* 数字字体栈 */
font-family:
  "SF Mono",              /* iOS/macOS 等宽 */
  "Menlo",                /* macOS 等宽 */
  "Consolas",             /* Windows 等宽 */
  "Courier New",
  monospace;
```

### 3.2 字体层级

| 层级 | 字号 | 字重 | 用途 | 示例 |
|------|------|------|------|------|
| **H0 特大** | 72px | 700 | 在一起天数 | `2,280` |
| **H1 大标题** | 28px | 600 | 页面标题 | 我们的时光 |
| **H2 副标题** | 22px | 600 | 弹窗标题、卡片标题 | 设置纪念日 |
| **H3 小标题** | 16-18px | 500 | 区域标题 | 今日推荐 |
| **Body 正文** | 15-16px | 400 | 情话正文 | "遇见你..." |
| **Caption 辅助** | 13-14px | 400 | 标签、说明文字 | "X年X个月X天" |
| **Small 最小** | 12px | 400 | 底部导航标签 | "纪念日" |

### 3.3 行高

| 场景 | 行高 | 说明 |
|------|------|------|
| 大数字 | 1.1 | 紧凑，数字紧密排列 |
| 标题 | 1.3 | 适中 |
| 情话正文 | 1.8 | 宽松，便于阅读诗歌感文字 |
| 辅助文字 | 1.4 | 标准 |

### 3.4 字间距

| 场景 | letter-spacing | 说明 |
|------|----------------|------|
| 页面标题 | 2px | 增强仪式感 |
| 正文 | 0 | 默认 |
| 数字 | 0 | 等宽字体自带均匀间距 |

## 4. 间距系统

### 4.1 基准单位

以 **4px** 为基准单位，所有间距为其倍数。

| Token | 值 | 用途 |
|-------|-----|------|
| `xs` | 4px | 紧密元素间距 |
| `sm` | 8px | 相关元素间距 |
| `md` | 12px | 区块内间距 |
| `lg` | 16px | 内容区 padding |
| `xl` | 20px | 卡片内 padding |
| `2xl` | 24px | 区域间距 |
| `3xl` | 28px | 大区块间距 |
| `4xl` | 32px | 卡片 padding、弹窗 padding |
| `5xl` | 40px | 页面顶部留白 |

### 4.2 布局规范

```
┌──────────────────────────────────┐
│           5xl (40px)             │  ← 页面顶部呼吸空间
├──────────────────────────────────┤
│                                  │
│        标题 (H1, 28px)           │
│                                  │
├──────────────────────────────────┤
│           3xl (28px)             │  ← 标题与卡片间距
├──────────────────────────────────┤
│  ┌────────────────────────────┐  │
│  │    毛玻璃卡片                │  │
│  │    padding: 4xl (32px)     │  │  ← 卡片内边距
│  │    元素间距: lg~2xl          │  │
│  └────────────────────────────┘  │
├──────────────────────────────────┤
│           2xl (24px)             │  ← 卡片与按钮间距
├──────────────────────────────────┤
│          按钮区                   │

│        env(safe-area-inset-bottom)│
└──────────────────────────────────┘
         max-width: 414px
```

## 5. 形状与光影

### 5.1 圆角

| 元素 | 圆角值 | 说明 |
|------|--------|------|
| 卡片 | `20px` (`--radius`) | 大圆角，柔和感 |
| 按钮 | `50px` | 胶囊形（全圆角） |
| 日期输入框 | `12px` | 中小圆角 |
| 进度环 | 正圆 | SVG circle |

### 5.2 阴影

```css
/* 卡片阴影 — 唯一使用的阴影 */
--shadow: 0 8px 32px rgba(255, 154, 158, 0.2);
```

| 属性 | 值 | 说明 |
|------|-----|------|
| X 偏移 | 0 | 居中投射 |
| Y 偏移 | 8px | 轻微向下 |
| 模糊 | 32px | 大范围柔和扩散 |
| 颜色 | `rgba(255,154,158,0.2)` | 粉色半透明 |

```css
/* 按钮阴影 */
box-shadow: 0 4px 15px rgba(255, 154, 158, 0.4);
```

### 5.3 毛玻璃

```css
background: var(--white-60);
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);  /* iOS Safari 必须 */
border: 1px solid var(--white-30);
border-radius: var(--radius);
box-shadow: var(--shadow);
```

> **兼容说明**：`backdrop-filter` 在 iOS Safari 9+ 和微信内置浏览器中均有良好支持。

## 6. 动效规范

### 6.1 过渡时间

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 微交互 | 0.3s | `ease` | 按钮点击、颜色切换、悬停 |
| 页面过渡 | 0.35s / 0.25s | `ease-out` / `ease-in` | 路由切换（入/出） |
| 数字动画 | 1.2s | `ease-out cubic` | 天数数字滚动 |
| 进度环 | 1.5s | `ease` | 进度条填充 |
| 粒子动画 | 8-20s | `linear infinite` | 爱心飘落 |

### 6.2 缓动函数

| Token | 值 | 使用场景 |
|-------|-----|----------|
| `ease-default` | `cubic-bezier(0.25, 0.1, 0.25, 1)` → `ease` | 按钮、颜色变化 |
| `ease-out` | `cubic-bezier(0, 0, 0.2, 1)` → `ease-out` | 元素出现 |
| `ease-in` | `cubic-bezier(0.4, 0, 1, 1)` → `ease-in` | 元素消失 |
| `ease-smooth` | `1 - (1-t)³` | 数字滚动（JS easeOutCubic） |

### 6.3 交互反馈

| 交互 | 反馈 | 实现 |
|------|------|------|
| 按钮点击 | 缩小至 95% + 阴影减弱 | `transform: scale(0.95)` + `box-shadow` |
| 心形收藏 | 放大 1.3 倍 → 弹回 | `@keyframes heartbeat` |
| 弹窗出现 | 遮罩淡入 + 卡片 scale(0.9→1) | `<Transition>` |
| 卡片出现 | 从下方 15px 淡入 | `@keyframes fadeInUp` |
| 页面切换 | 左右滑动 + 透明度 | Vue `<Transition>` |

### 6.4 动效原则

| 原则 | 说明 |
|------|------|
| 动效有意义 | 每个动画传达信息（状态变化、层级关系） |
| 不超过 2 秒 | 所有动画（除粒子循环）在 2 秒内完成 |
| 不阻塞交互 | 动效期间用户可以继续操作 |
| 减少动效偏好 | v1.0 暂不使用 `prefers-reduced-motion`，后续版本考虑 |

## 7. 组件规范

### 7.1 按钮

```
┌─────────────────────────────────┐
│          按钮文字                 │
│     padding: 12px 28px          │
│     border-radius: 50px         │
│     font-size: 16px / weight 600│
└─────────────────────────────────┘
```

**变体**：

| 变体 | 背景 | 文字色 | 类名 |
|------|------|--------|------|
| Primary | `linear-gradient(pink → pink-deep)` | `white` | `.btn` |
| Secondary | `white-60` | `text` | `.btn--secondary` |

**状态**：

| 状态 | 表现 |
|------|------|
| Default | 正常显示 + 粉色阴影 |
| Active | `scale(0.95)` + 阴影减弱 |
| Disabled | `opacity: 0.5` + `cursor: not-allowed` |

**最小点击区域**：44×44px（符合 iOS HIG）

### 7.2 毛玻璃卡片

```
┌──────────────────────────────┐
│                              │
│  padding: 28-32px            │
│  background: white-60        │
│  backdrop-filter: blur(20px) │
│  border-radius: 20px         │
│  border: 1px white-30        │
│  box-shadow: pink glow       │
│                              │
└──────────────────────────────┘
```

### 7.3 情话卡片（QuoteCard 变体）

在基础毛玻璃卡片上增加：
- 顶部大引号装饰（`font-size: 48px`, 粉色 30% 透明度, Georgia 衬线字体）
- 正文 20px，行高 1.8
- 底部心形收藏按钮 28px，居中
- 进入动画：fadeInUp 0.5s

### 7.4 底部导航栏

```
┌────────────────────────────────────┐
│         ┌────────┬────────┐        │
│         │  💕    │  💌    │        │
│         │ 纪念日  │ 每日情话│        │
│  padding: 8px 0                    │
│  background: white-80              │
│  backdrop-filter: blur(20px)      │
│  border-top: 1px white-30          │
│  padding-bottom: safe-area-inset   │
└────────────────────────────────────┘
```

**状态**：
- 激活：文字色 `pink-deep (#e8728a)`
- 默认：文字色 `text-light (#7a6070)`

### 7.5 进度环（SVG）

```
         ┌──────────┐
         │    ╭──╮   │
         │   ╱    ╲  │  viewBox: 0 0 120 120
         │  │  60  │ │  r = 52
         │  │  天  │ │  stroke-width = 6
         │   ╲    ╱  │  stroke-linecap: round
         │    ╰──╯   │  旋转 -90° 从 12 点开始
         └──────────┘
```

- 背景环：白色 30% 透明度
- 前景环：粉色渐变（`#ff9a9e → #e8728a`）+ `drop-shadow(0 0 6px pink glow)`

│   │   │    日期选择器        │     │     │
│   │   └────────────────────┘     │     │

## 9. 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| 手机 | ≤ 414px | 全宽显示，标准布局 |
| 平板/桌面 | > 414px | 内容区最大 414px 居中，两侧显示渐变背景 |

```css
#app {
  max-width: 414px;   /* iPhone 11/12/13 Pro Max */
  margin: 0 auto;     /* 居中 */
}
```

- 无媒体查询（移动优先设计，桌面端只是居中展示）
- 不针对平板做大屏适配

## 10. 可访问性

| 项目 | 状态 | 说明 |
|------|------|------|
| 颜色对比度 | 部分达标 | 粉色背景 + 白色文字对比度偏低，依赖文字阴影增强 |
| 焦点指示 | 未实现 | v1.0 主要面向触屏，无键盘导航需求 |
| 语义 HTML | 基本覆盖 | 使用了 `<nav>`、`<h1>`、`<h2>`、`aria-label` |
| 减少动效 | 未实现 | 后续版本可增加 `prefers-reduced-motion` 支持 |
| 屏幕阅读器 | 部分支持 | 粒子动画有 `aria-hidden="true"`，收藏按钮有 `aria-label` |
