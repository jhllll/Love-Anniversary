## 2. 架构师视角：技术优化分析

### 2.1 路由懒加载 + 构建分包

**问题**：src/router/index.js 使用顶层静态 import 加载全部 3 个页面组件，首屏打包时所有页面代码一并下载。

**方案**：
- 静态 import 改为动态 import() 懒加载
- vite.config.js 添加 manualChunks，将 vue 和 vue-router 拆分为独立 vendor chunk（99.73 kB）
- build.target 设为 es2020，减小 polyfill 体积

**收益**：
- 首屏仅加载 Home 页面（~7 kB），Quotes（~3 kB）和 Games（~12 kB）按需加载
- vendor 独立后可被浏览器缓存，后续访问跳过 99.73 kB
- 构建产物从单一 bundle 拆分为 7 个独立 chunk

### 2.2 KeepAlive 缓存 + onDeactivated 游戏重置

**问题**：Games.vue 使用 4 个 v-if 切换游戏，组件被完全销毁重建。用户期望切走 Tab 后游戏重置。

**方案**：
- KeepAlive :max=4 包裹动态 component :is 替代 4 个 v-if
- tabs 常量提升到模块顶层，避免每次渲染重新创建
- 4 个游戏组件各添加 onDeactivated 钩子，切走时清理定时器 + 重置 started = false

**收益**：
- 组件实例复用，避免反复销毁/创建
- DOM Diff 从 4 个 v-if 简化为单个 component :is
- 切回时显示开始遮罩，符合产品预期

### 2.3 收藏数据索引→文本迁移

**问题**：favorites 存储情话数组索引，quotes 数组增删或排序会导致索引指向错误。

**方案**：
- loadFavorites() 兼容旧格式：首个元素为 number → 自动映射为文本并保存新格式
- isFavorited / toggleFavorite 改为基于文本内容匹配
- favoriteQuotes 由 { index, text } 简化为 { text }

**收益**：
- 数据与数组位置解耦，情话数据可自由增删而不影响收藏
- 旧数据自动迁移，用户无感知

### 2.4 GameStartOverlay 共享组件

**问题**：4 个游戏组件各自实现相同开始遮罩，约 30 行 x 4 = 120 行重复代码。

**方案**：
- 提取为 src/components/games/GameStartOverlay.vue
- 通过 props（emoji / title / description / buttonText）传入差异化内容
- start 事件通知父组件

**收益**：减少约 100 行重复代码，样式和交互统一维护。

### 2.5 6 项 Bug 修复

| 编号 | 问题 | 修复 | 严重度 |
|------|------|------|--------|
| 5.1 | HeartParticles computed 无响应式依赖 | 改为常量 | 中 |
| 5.2 | CountdownDisplay 未声明 ref + rAF 未清理 | 移除 ref + onUnmounted 取消 rAF | 高 |
| 5.3 | GachaGame setTimeout 未清理 + 历史无上限 | 存入 Set + slice(-5) 限制 | 高 |
| 5.4 | BubbleGame setTimeout 未清理 | 存入 Set，onUnmounted 遍历清理 | 高 |
| 5.5 | AnniversarySetter prop 变化不响应 | watch props.currentDate 同步 | 中 |
| 5.6 | #app overflow:hidden 裁剪纵向 | 改为 overflow-x: hidden | 中 |

### 2.6 CSS 动画去重

**问题**：fadeInUp 和 toast-in 关键帧在多个组件中重复定义。

**方案**：提取到 global.css，组件删除重复定义。

**收益**：减少 CSS 冗余，统一动画参数。

## 3. 产品经理视角：影响评估

### 3.1 用户体验影响

| 变更 | 用户感知 | 影响 |
|------|----------|------|
| 路由懒加载 | 首屏加载更快 | 正向 |
| KeepAlive + 重置 | 切换 Tab 游戏回到初始状态 | 符合预期 |
| 收藏数据迁移 | 无感知自动迁移 | 无影响 |
| GameStartOverlay | 视觉和交互完全一致 | 无影响 |
| Bug 修复 | 页面正常滚动、日期预填正确、无内存泄漏 | 正向 |

### 3.2 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 懒加载路由切换白屏 | 低 | 中 | 页面组件 <15 kB，网络延迟可忽略 |
| KeepAlive 内存占用 | 低 | 低 | max=4 限制最大缓存实例 |
| 旧格式收藏迁移失败 | 低 | 中 | try-catch + filter(Boolean) 容错 |
