## 快速开始

### 怎么打开？

你的他（丈夫）会通过微信发给你一个链接，点开就行了。

就像平时点开朋友圈文章一样简单，不需要下载 App，不需要注册登录。

### 添加到手机桌面（推荐）

在微信中打开后，可以添加到 iPhone 桌面，下次像普通 App 一样打开：

1. 点击微信右上角的 `...` 按钮
2. 选择「在 Safari 中打开」
3. 在 Safari 中，点击底部中间的分享按钮（方框+箭头图标）
4. 滑动找到「添加到主屏幕」
5. 点击右上角「添加」

完成后，桌面会出现一个 💕 图标的快捷方式，取名"我们的时光"。

## 功能介绍

这个小应用有两个功能：
1. **纪念日倒计时**：看看我们在一起多少天了
2. **每日情话**：每天一句甜甜的话

底部有两个按钮可以切换：
- 💕 纪念日
- 💌 每日情话

## 纪念日倒计时

### 第一次打开

第一次打开时，会弹出一个设置窗口，让你选择**你们在一起的第一天**。

```
┌──────────────────────────┐
│                          │
│      设置纪念日           │
│  选择你们在一起的那一天    │
│                          │
│  ┌────────────────────┐  │
│  │   选择日期 →        │  │
│  └────────────────────┘  │
│                          │
│       [ 确认设置 ]        │
│                          │
└──────────────────────────┘
```

1. 点击日期选择器
2. 在日历中滑到你们在一起的那一天
3. 点击「确认设置」

> **提示**：要选择你们正式确认关系的第一天哦，不是结婚纪念日（如果你想设结婚纪念日也完全没问题，你开心就好 😊）。

### 设置后看到的

设置完成后，页面会显示：

```
        我们在一起的第
           2,280
            天
    ─────────────────
     6 年   3 个月   5 天
    ─────────────────
       ┌───────┐
       │ 距离  │
       │ 纪念日 │
       │ 85天  │
       └───────┘
  2027年5月20日 · 7周年纪念日
```

| 显示内容 | 说明 |
|----------|------|
| 大数字 | 从在一起第一天到今天，一共多少天 |
| 年/月/天 | 更直观的恋爱时长 |
| 进度环 | 距离下一个纪念日还有多久 |
| 日期标签 | 下一个纪念日是什么时候、几周年 |

### 修改纪念日

如果你发现日期填错了：

1. 点击「修改纪念日」按钮
2. 在弹窗中重新选择正确的日期
3. 点击「确认设置」

数据会立即更新。

> **注意**：所有数据都存在你的手机上，别人看不到。修改纪念日也只影响你自己的手机。

## 每日情话

### 怎么看情话？

点击底部的「💌 每日情话」，切换到情话页面。

每天都会有一句不同的情话等着你：
```
    "
  遇见你，是我这辈子最美丽的意外。

              🤍
```

### 换一句

如果今天的情话你想换换口味，点击「换一句 ✨」按钮，会随机换成另一句。

> 今天的情话不会丢失，明天打开还是会显示今天原本的那句哦。

### 收藏喜欢的情话

看到喜欢的情话，点击心形按钮收藏：

- 空心 🤍 → 点击 → 实心 ❤（已收藏）
- 实心 ❤ → 点击 → 空心 🤍（取消收藏）

收藏的情话会在页面下方「我的收藏」区域显示，随时可以回看。

```
我的收藏 (3)
┌──────────────────────────┐
│ 你的笑容，是我每天起床的动力  │  ❤
└──────────────────────────┘
┌──────────────────────────┐
│ 世界很大，我的心很小...      │  ❤
└──────────────────────────┘
```

> 收藏不会丢失，就算关掉页面明天再打开，收藏的情话都还在。

## 常见问题

### Q1：数据会丢失吗？
数据存在你手机的浏览器缓存里。只要不主动清除 Safari/微信的浏览数据，就不会丢失。

如果哪天发现数据没了（比如清理了手机缓存），重新设置纪念日就行，情话也可以重新收藏。

### Q2：能在多台手机上同步吗？
目前不能。数据只在你当前使用的手机上。如果你想在 iPad 上也看，需要分别设置。

### Q3：安全吗？我的数据会被上传吗？
完全安全。这个小应用**没有服务器**，你的纪念日和收藏数据**只存在你手机里**，不会上传到任何地方。他也不需要后台数据库。

### Q4：没有网络能用吗？
第一次打开需要网络加载页面。加载完成后，后面的数据计算都在手机上完成，断网也不影响使用。

不过切到情话页时情话数据是和页面一起下载的（30 条都在），所以加载一次后也不需要网络。

### Q5：怎么把这个发给闺蜜？
这是你的专属小应用。把链接发给她，她可以设置自己的纪念日，完全不会影响你的数据（每个人的纪念日存在自己手机里）。

### Q6：页面打不开怎么办？
1. 检查网络连接
2. 让老公重新发一下链接
3. 或者让老公刷新一下 GitHub Pages 部署
