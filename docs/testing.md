#### TC-002：在一起天数展示

| 项目 | 内容 |
|------|------|
| **编号** | TC-002 |
| **模块** | 首页 - 天数展示 |
| **前置条件** | 已设置纪念日（如 `2020-05-20`） |
| **优先级** | P0 |

**测试步骤**：

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 设置纪念日为 `2020-05-20` | 页面加载后数字从 0 滚动到目标值（有动画） |
| 2 | 手动计算天数 | 大数字 = 当天 - 2020-05-20 的自然日差值 |
| 3 | 验证恋爱时长 | 下方显示 X 年 X 个月 X 天，计算正确 |
| 4 | 验证动画 | 三个数字（年/月/天）依次滚动加载，有先后 |

**关键公式**：
```
总天数 = floor((new Date() - new Date("2020-05-20")) / 86400000)
```

## 4. UI 验证清单

### 4.1 首页视觉检查

- [ ] 背景粉色渐变自然过渡
- [ ] 标题"我们的时光"白色字体 + 阴影
- [ ] 大天数数字粉红渐变色，72px，居中
- [ ] 毛玻璃卡片有模糊背景效果
- [ ] 进度环从 12 点方向开始，粉色发光
- [ ] "修改纪念日"按钮白色半透明，点击有缩放反馈
- [ ] 底部导航固定，两个图标对齐
- [ ] 爱心粒子连续飘落，不卡顿
- [ ] 数字动画流畅无闪烁

### 4.2 情话页视觉检查

- [ ] 返回按钮白色，点击区域足够大
- [ ] 情话卡片圆角 20px，有阴影
- [ ] 大号引号装饰半透明粉色
- [ ] 心形按钮有动画
- [ ] 收藏列表每项独立卡片
- [ ] 页面底部有留白，内容不被遮挡

### 4.3 移动端检查

- [ ] 414px 宽度下布局居中，无横向滚动条
- [ ] iPhone 底部安全区域适配正常
- [ ] 点击元素无默认高亮（`-webkit-tap-highlight-color`）
- [ ] 字体大小适合手机阅读（最小 12px）
- [ ] 所有可点击区域 ≥ 44x44px（iOS 人机界面指南）

## 6. 缺陷严重等级

| 等级 | 定义 | 示例 |
|------|------|------|
| P0 - 致命 | 核心功能不可用 | 纪念日设置后白屏；情话页 404 |
| P1 - 严重 | 主要功能异常 | 天数计算错误；收藏刷新丢失 |
| P2 - 一般 | 次要功能异常 | 动画不流畅；某款手机样式偏移 |
| P3 - 建议 | 体验优化 | 文案可优化；动画时长可调整 |
