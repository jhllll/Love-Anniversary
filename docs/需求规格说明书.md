## 1. 产品概述

### 1.1 产品定位

一款纯前端、无服务器的浪漫 SPA（Single Page Application），帮助丈夫向妻子表达爱意。核心包含纪念日倒计时、每日情话推荐，以及 4 款恋爱主题小游戏。

### 1.2 核心价值

- **纪念日倒计时**：让妻子随时看到两人在一起的天数、时长，以及距离下一个纪念日的倒计时
- **每日情话**：每天推荐一句情话，可收藏喜欢的句子，给妻子每天一份甜蜜的小惊喜
- **小游戏**：4 款恋爱主题小游戏（戳泡泡/翻牌记忆/接爱心/扭蛋机），增添互动趣味

### 1.3 使用场景

- 丈夫将链接通过微信发给妻子
- 妻子在 iPhone 微信内置浏览器中打开
- 首次进入设置纪念日，之后每次打开即可看到倒计时和情话

## 2. 功能需求

### 2.1 纪念日倒计时（首页 `/`）

#### 2.1.1 首次设置

| 需求编号 | FR-001 |
|----------|--------|
| 描述 | 用户首次进入应用时，自动弹出纪念日设置面板 |
| 触发条件 | localStorage 中无 `love-app-anniversary` 数据 |
| 交互流程 | 弹窗遮罩 → 日期选择器 → 确认按钮 → 保存到 localStorage → 关闭弹窗 |
| 日期限制 | 不可选择未来日期（max = 当天） |
| 异常处理 | 未选择日期时确认按钮置灰不可点击 |

#### 2.1.2 在一起天数展示

| 需求编号 | FR-002 |
|----------|--------|
| 描述 | 大字号展示"我们在一起的第 X 天" |
| 计算逻辑 | 当前日期 - 纪念日日期，向下取整天数 |
| 动画效果 | 页面加载时数字从 0 滚动到目标值（ease-out cubic，1.2 秒） |
| 精确度 | 基于自然日，非 24 小时精确 |

#### 2.1.3 恋爱时长

| 需求编号 | FR-003 |
|----------|--------|
| 描述 | 展示精确到"X 年 X 个月 X 天"的恋爱时长 |
| 计算逻辑 | 年份差 + 月份差（含借位处理）+ 日期差（含借位处理） |
| 边界处理 | 负数情况回退为 0 |

#### 2.1.4 纪念日倒计时

| 需求编号 | FR-004 |
|----------|--------|
| 描述 | 展示距离下一个纪念日还有多少天 |
| 计算逻辑 | 下一个纪念日 = 今年纪念日（若已过则为明年纪念日），天数 = ceil((纪念日 - 今天) / 86400000) |
| 进度展示 | SVG 环形进度条，百分比 = 今年已过天数 / 365（或 366） |
| 动效 | 进度条带粉红发光滤镜（drop-shadow），1.5 秒过渡动画 |
| 文案 | "YYYY年M月D日 · N周年纪念日" |

#### 2.1.5 修改纪念日

| 需求编号 | FR-005 |
|----------|--------|
| 描述 | 提供"修改纪念日"按钮，点击弹出设置面板 |
| 交互 | 与首次设置共用同一个弹窗组件，打开时预填当前值 |
| 确认后 | 所有计算立即更新 |

### 2.2 每日情话（`/quotes`）

#### 2.2.1 今日情话

| 需求编号 | FR-006 |
|----------|--------|
| 描述 | 根据当天日期展示一句情话，同一天始终展示同一句 |
| 算法 | `hash(YYYY-M-D) % 30` → 得到情话索引 |
| 哈希算法 | JS 整数哈希：`((hash << 5) - hash) + charCode`，取绝对值 |
| 稳定性 | 同一日期多次打开，始终显示同一句情话 |

#### 2.2.2 随机换一句

| 需求编号 | FR-007 |
|----------|--------|
| 描述 | 点击"换一句"按钮随机切换到另一句情话 |
| 逻辑 | `Math.random()` 选取，且不重复当前显示的那一句（当情话总数 > 1 时） |
| 作用域 | 仅影响当前页面展示，不影响收藏数据 |

#### 2.2.3 收藏情话

| 需求编号 | FR-008 |
|----------|--------|
| 描述 | 情话卡片上有收藏按钮（心形图标），点击切换收藏状态 |
| 存储 | localStorage key: `love-app-favorites`，值为索引数组 JSON |
| 展示 | "我的收藏"区域列出所有已收藏情话，可取消收藏 |
| 持久化 | 刷新页面 / 重新打开，收藏不丢失 |

## 3. 用户故事

### US-01：首次打开设置纪念日

> 作为妻子，我第一次打开这个链接，想在弹窗中选择我们在一起的日期，然后看到我们在一起的天数。

**验收标准：**
- [ ] 首次进入显示半透明遮罩 + 设置面板
- [ ] 日期选择器不可选未来日期
- [ ] 确认后关闭弹窗，立即显示倒计时数据
- [ ] 再次打开不再弹出设置面板

### US-02：查看恋爱天数与纪念日倒计时

> 作为妻子，我打开页面就能看到我们在一起多少天、距离下一个纪念日还有多久。

**验收标准：**
- [ ] 大字号显示"我们在一起的第 X 天"
- [ ] 精确展示 X 年 X 个月 X 天
- [ ] 环形进度条带发光效果
- [ ] 展示下一次纪念日的具体日期和周年数
- [ ] 数字有滚动加载动画

### US-03：修改纪念日

> 作为用户，我可能填错了日期，需要能够修改。

**验收标准：**
- [ ] 点击"修改纪念日"弹出设置面板
- [ ] 面板预填当前值
- [ ] 确认后所有数据即时更新

### US-04：查看每日情话

> 作为妻子，我切换到情话页面，能看到今天推荐的一句情话，可以收藏我喜欢的。

**验收标准：**
- [ ] 展示今日情话，同一天内容不变
- [ ] 可以点击"换一句"随机切换
- [ ] 可以点击心形按钮收藏/取消收藏
- [ ] 收藏的情话在下方列表展示
- [ ] 刷新后收藏不丢失

### US-05：玩小游戏

> 作为妻子，我想在等车/无聊的时候玩一下恋爱主题的小游戏。

**验收标准：**
- [ ] 底部导航可切换到"小游戏"tab
- [ ] 4 个游戏 Tab 可切换（泡泡/翻牌/接爱心/扭蛋）
- [ ] 每个游戏需要点击"开始游戏"才能开始
- [ ] 戳泡泡可点击戳破得分
- [ ] 翻牌记忆有 3 秒预览阶段
- [ ] 接爱心可手指滑动控制篮子，速度逐渐加快
- [ ] 扭蛋机有抖动动画和随机结果

## 5. 数据字典

### 5.1 localStorage 数据

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `love-app-anniversary` | `string` | ISO 格式纪念日日期 | `"2020-05-20"` |
| `love-app-favorites` | `string` (JSON) | 收藏情话索引数组 | `"[0, 5, 12]"` |

### 5.2 computed 数据流

```
anniversary (ref)
    ├── daysTogether (computed)
    │     = floor((today - anniversary) / 86400000)
    ├── durationText (computed)
    │     = { years, months, days } 含借位逻辑
    ├── nextAnniversary (computed)
    │     = 今年或明年的纪念日 Date 对象
    ├── daysUntilNext (computed)
    │     = ceil((nextAnniversary - today) / 86400000)
    ├── progress (computed)
    │     = round((今天 - 上次纪念日) / (下次 - 上次) * 100)
    └── nextAnniversaryLabel (computed)
          = "YYYY年M月D日 · N周年纪念日"
```

### 5.3 情话数据

| 字段 | 说明 |
|------|------|
| 数据源 | `src/data/quotes.js`，硬编码 30 条中文情话 |
| 格式 | `string[]` |
| 索引 | 0-29 |

## 6. 技术约束

| 约束项 | 说明 |
|--------|------|
| 技术栈 | Vue 3 + Vite + Vue Router 4 |

## 7. 名词解释

| 术语 | 说明 |
|------|------|
| 纪念日 | 用户设定的恋爱开始日期，每年该日期为周年纪念日 |
| 在一起天数 | 从纪念日到当天的自然日差 |
| 恋爱时长 | 以年月日为单位的精确时长 |
| 进度环 | SVG 环形图，表示距离下一个纪念日的进度百分比 |
| 毛玻璃 | CSS `backdrop-filter: blur()` 实现的半透明模糊效果 |
| 爱心粒子 | 纯 CSS 动画实现的背景装饰爱心飘落效果 |
